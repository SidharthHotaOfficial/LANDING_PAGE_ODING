# Landing Page — The Odin Project

A simple landing page built as part of **The Odin Project Foundations** course.

This project focuses on practicing **HTML structure, CSS styling, and Flexbox layouts** to recreate a modern landing page from scratch.

## Features

* Footer
* Consistent color scheme based on The Odin Project design

## What I Learned

Through this project, I practiced:

* Structuring webpages using semantic HTML
* Using CSS Flexbox for layouts
* Aligning and spacing elements with Flexbox
* Creating navigation bars
* Styling buttons and sections
* Using `justify-content`, `align-items`, `gap`, and `flex-direction`
* Working with CSS typography and colors
* Organizing HTML and CSS into separate files
